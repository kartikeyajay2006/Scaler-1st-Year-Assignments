# 🌐 Web Foundations: First-Year Assignments

**12 hand-written HTML and CSS pages from my first year, covering semantic markup, forms, layout, CSS shapes and animation.**

No frameworks and no build step: open any `.html` file in a browser.

## Pages

| Page | Concepts |
|---|---|
| [`first_webpage.html`](first_webpage.html) | Basic document structure, headings, links and images |
| [`semantic_webpage.html`](semantic_webpage.html) | `header`, `nav`, `main`, `article`, `section` and `footer` |
| [`profile_card.html`](profile_card.html) | Box model, borders and centred card layout |
| [`recipe_page.html`](recipe_page.html) | Ordered and unordered lists, images and typography |
| [`weekend_plan.html`](weekend_plan.html) | Nested lists |
| [`movie_collection.html`](movie_collection.html) | Tables and media |
| [`contact_form.html`](contact_form.html) | Forms, input types and labels |
| [`grid_layout.html`](grid_layout.html) | CSS Grid |
| [`dog_galary/dog_galary.html`](dog_galary/dog_galary.html) | Responsive image gallery (9 breeds) |
| [`shapes.html`](shapes.html) | Drawing shapes with pure CSS |
| [`moon_orbit.html`](moon_orbit.html) | CSS keyframe animation: a moon orbiting the earth |
| [`ferris_wheel.html`](ferris_wheel.html) | CSS transforms and rotation animation |
